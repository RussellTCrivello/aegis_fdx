# Production Packaging Plan — Windows 10/11 x64

Status: **Production Release Specification**  
Baseline: Commit `64f7cb5` on `arena/01a084ba-aegis-fdx`  
Target Platform: Windows 10 / Windows 11 (x64)

---

## 1. Architectural Objectives

1. **Zero-Dependency Installation**: The application must run without requiring a pre-installed Java Runtime Environment (JRE) or JavaFX runtime on the target forensic workstation.
2. **Deterministic & Self-Contained**: All runtime components (Java 21 JVM modules, JavaFX 21 native DLLs, SQLite native binaries, Lucene 9.x search libraries) are bundled into the distribution directory.
3. **Forensic Integrity**: The installation directory is read-only for standard users; mutable case files (`case.db`, Lucene indexes, audit logs) reside strictly within the investigator's selected case directory.
4. **Offline Capability**: The packaged binary contains all necessary components and operates with zero outbound network calls.

---

## 2. Packaging Toolchain & Requirements

| Component | Required Tool / Version | Purpose |
|---|---|---|
| **JDK** | OpenJDK 21 LTS (`bin/javac`, `bin/jar`, `bin/jlink`, `bin/jpackage`) | Core compilation, runtime trimming, native packaging |
| **JavaFX SDK** | JavaFX 21.0.4+ Windows x64 (`lib/*.jar`, `bin/*.dll`) | UI controls, graphics pipeline, native DWM windowing |
| **Wix Toolset** | WiX Toolset v3.11+ (`candle.exe`, `light.exe`) | MSI generation, Windows Installer registry registration |
| **Code Signing** | Microsoft `signtool.exe` + Authenticode Certificate (`.pfx`) | Binary signing, SmartScreen reputation, tamper detection |

## 4. JLink Module Trimming

The runtime image is generated using `jlink` to produce an optimized ~45 MB runtime rather than shipping a full ~200 MB JDK:

```bash
jlink \
  --add-modules java.base,java.desktop,java.logging,java.management,java.naming,java.sql,java.xml,java.prefs,jdk.crypto.ec,jdk.unsupported,jdk.zipfs \
  --strip-debug \
  --no-header-files \
  --no-man-pages \
  --compress=zip-6 \
  --output build/runtime
```

## 5. JPackage Windows Installer Configuration

```powershell
jpackage `
  --name "AEGIS-FDX" `
  --app-version "1.0.0" `
  --vendor "AEGIS Forensics" `
  --description "Digital forensics and e-discovery evidence processing platform" `
  --input "build/jars" `
  --main-jar "aegis-fdx-1.0.0.jar" `
  --main-class "com.aegis.fdx.Launcher" `
  --runtime-image "build/runtime" `
  --dest "dist" `
  --type "msi" `
  --win-dir-chooser `
  --win-menu `
  --win-menu-group "AEGIS Forensics" `
  --win-shortcut `
  --win-shortcut-prompt `
  --win-upgrade-uuid "6f3a1c92-4d7b-4f2e-9a15-8c0b7e2d4a63" `
  --license-file "packaging/LICENSE.txt" `
  --icon "packaging/aegis.ico" `
  --java-options "-Xmx4g" `
  --java-options "-XX:+UseZGC" `
  --java-options "-XX:MaxGCPauseMillis=50" `
  --java-options "-Dfile.encoding=UTF-8" `
  --java-options "--add-opens=java.base/java.lang=ALL-UNNAMED"
```

## 6. Verification & Quality Gates for Packaged Artifacts

1. **Clean Installation**: Silent install (`msiexec /i AEGIS-FDX-1.0.0.msi /qn`) installs cleanly into Program Files or LocalAppData.
2. **Deterministic Hashes**: All produced `.msi`, `.exe`, and `.zip` archives are hashed with SHA-256 and verified against `packaging/SOURCE-MANIFEST.txt`.
3. **Execution Smoke Test**: Packaged `AEGIS-FDX.exe` launches, loads SQLite native driver, creates a new forensic case, executes indexing, and terminates cleanly with exit code 0.
4. **Clean Uninstall**: `msiexec /x AEGIS-FDX-1.0.0.msi /qn` cleanly removes all program binaries and registry keys without touching user evidence cases.
